## ✨ Descripción

Portafolio moderno y minimalista construido con las últimas tecnologías del ecosistema React. Diseñado para ofrecer una experiencia de usuario excepcional con animaciones fluidas, dark mode nativo y optimización de rendimiento.

## 🚀 Características

- 🌓 **Dark Mode** - Cambio suave entre temas con View Transitions API
- ⚡ **Ultra Rápido** - Optimizado con Vite y lazy loading
- 🎨 **Animaciones Premium** - Framer Motion para interacciones fluidas
- 📱 **100% Responsive** - Diseño adaptable a todos los dispositivos
- ♿ **Accesible** - Cumple estándares WCAG AA
- 🔒 **Formulario Seguro** - Validación con Zod y React Hook Form
- 🎯 **SEO Optimizado** - Metadatos y estructura semántica

## 🛠️ Stack Tecnológico

- **Framework:** React 19 + TypeScript 5.8
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion 12
- **Forms:** React Hook Form + Zod
- **Icons:** Lucide React
- **Linting:** ESLint + Prettier

## 📦 Instalación

```bash
# Clonar repositorio
git clone https://github.com/Alecwce/portafolio-alexwce.git

# Instalar dependencias
pnpm install

# Iniciar servidor desarrollo
pnpm dev

# Build producción
pnpm build
```
